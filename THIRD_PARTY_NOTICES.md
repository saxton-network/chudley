## Character and meme lineage

Chudley's visual inspiration descends from the character commonly documented as **MAGA Wojak**.

The earliest currently documented surviving use located for this project is an anonymous post on 4chan's `/pol/` board dated **July 11, 2018**. Public meme-history references describe that as the earliest known use while also noting that the true original creator is uncertain.

Reference:

- Know Your Meme: <https://knowyourmeme.com/memes/maga-wojak-magatard>

Because the early source is anonymous and the true origin is not established, this repository does not attribute authorship beyond what can be supported.
